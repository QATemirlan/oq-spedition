# OQ SPEDITION

Многостраничный статический сайт OQ SPEDITION для междугородних грузоперевозок по Казахстану.

## Публикация

`build_site.py` генерирует HTML-страницы направленных маршрутов между всеми городами справочника, услуг, автопарка, раздела `/tarify/`, sitemap.xml и robots.txt. Маршрутные данные, каталог машин и правила расчёта находятся в этом файле; тарифные ставки для раздела `/tarify/` вынесены в `data/tariffs_kz.csv`. Калькуляторы получают справочники из `routes.js` и `assets/tariffs.js`.

Для повторной генерации выполните `python3 build_site.py`. Сайт не требует пакетов и серверной сборки; для локального просмотра запустите `python3 -m http.server 8000` из папки проекта. Страницы используют префикс `SITE_PREFIX` из `build_site.py`, сейчас он настроен под GitHub Pages `/oq-spedition`.

В шапке расположено мегаменю с раскрытием при наведении/фокусе и нажатием на мобильных устройствах. Выбор города сохраняется в `localStorage` и фильтрует направления. Страницы генерируются для обоих направлений каждой пары городов; маршрутные пары без загруженных ставок показывают «по запросу».

Калькулятор принимает решение по тарифу в таком порядке: индивидуальная опубликованная цена выбранного автомобиля на конкретном маршруте, затем базовый тариф Газели для известных маршрутов Алматы, иначе — расчёт по запросу. Общие городские тарифы не подменяют маршрутные.

## Заявки

В статическом режиме форма подготавливает письмо на `logistics@oqspedition.kz`; сайт не отправляет заявки автоматически. Для прямой отправки заявок потребуется серверная часть и настроенный HTTPS endpoint.

## Локальный просмотр

Откройте `index.html` в браузере.

## Раздел `Тарифы`

Данные тарифов находятся в `data/tariffs_kz.csv`. Используются только колонки с тенге: `weight_1_5t_kzt`, `weight_3t_kzt`, `weight_5t_kzt`, `weight_7t_kzt`, `weight_10t_kzt`, `weight_20t_kzt`. Рублёвые колонки не используются и не должны добавляться в интерфейс.

Чтобы добавить новый город, добавьте строку с этим городом в `origin` или `destination`, затем выполните `python3 build_site.py`. Slug для URL создаётся автоматически функцией `slugify`.

Чтобы добавить новое направление, добавьте строку в `data/tariffs_kz.csv` с `origin`, `destination` и ценами по нужным весовым категориям. После генерации появятся SEO-страница `/tarify/<origin>-<destination>/` и страница результата `/tarify/raschet/<origin>-<destination>/`.

Чтобы изменить тариф, поменяйте значение в соответствующей колонке `weight_*_kzt` и пересоберите сайт. Пустое значение означает, что цена для категории не опубликована.

Чтобы изменить срок доставки или тип автомобиля, правьте функции `route_delivery_time` и `tariff_vehicle` в `build_site.py`. Для маршрутов Алматы срок подтягивается из существующего справочника `ROUTES`, для остальных направлений используется общий ориентир.

Правила расчёта веса задаются в `TARIFF_WEIGHT_LIMITS` и функции `select_weight_category`. Вес вводится в килограммах, переводится в тонны и попадает в ближайшую подходящую категорию сверху: 500 кг -> до 1,5 т, 2 000 кг -> до 3 т. Если в выбранной категории нет цены, используется следующая доступная большая категория. Если подходящей цены нет, сайт показывает «Рассчитаем стоимость индивидуально».
