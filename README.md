# OQ SPEDITION

Одностраничный сайт OQ SPEDITION для международных грузоперевозок.

## Публикация

`index.html` — автономная статическая версия сайта: изображения, стили и скрипты уже включены в файл. Она подходит для GitHub Pages и не требует сборки или зависимостей.

## Заявки

В статическом режиме форма подготавливает письмо на `logistics@oqspedition.kz`; сайт не отправляет заявки автоматически. Для прямой отправки заявок потребуется отдельный Node.js-хостинг, серверная часть и настроенный HTTPS webhook.

## Локальный просмотр

Откройте `index.html` в браузере.
